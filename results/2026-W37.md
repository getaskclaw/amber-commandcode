## Findings

1. **GA 修了预览版两个交付病。** A-791e90ac(预览版 7 秒交白卷「no code」)本道 6/6 满分;A-d9b79b46(UI 搭建,预览版 7.7 秒未交付文件)本道 12/12 满分——该卷史上仅三家通过(另两家成绩见 [amber-ollama](https://github.com/getaskclaw/amber-ollama)、[amber-devin](https://github.com/getaskclaw/amber-devin) 对应期)。
2. **防御/归因面大幅进化。** A-be92627f 拿 8/9——此卷八月以来全员 0–7/9,这是纪录;但注意案级通过线是全钉,8/9 仍计挂。A-a317e74b 拿 13/15(预览版 7/15,此前全员最佳 14/15)——归因精度进入第一档,同样差 2 钉未过线。
3. **「这是真 v4.1」的判据在分数之外。** 单案分数上 0731 与 v4.1 多处同分带(如 A-61f7ad01、A-cdc3d11a、A-be92627f),分数区分不开新旧脑。本道身份判定靠:① 裸 API 原生图探针实证原生视觉(0731 物理上读不了图);② token 经济学——本道全库 input 41K/卷,与预览版同带(84K/卷),0731 在三方道是 2.9M/卷,差两个数量级;③ 官方目录 0731 旧快照已于 GA 当日撤出,上游无旧脑可别名。
4. **审查面:干净卷史上最佳并列,对抗卷中场。** A-47eea242 拿 4(与此前全场最佳并列,预览版同卷只得 1,是同家族明显进步);A-cdc3d11a 拿 -2(全员同分带,最佳历史成绩为 +1)。
5. **视觉案:有眼睛,不会审图。** 原生视觉探针通过,但视觉审查卷命中 1/5、verdict 未交,d2=-1.0——与预览版同分同死法。
6. **no-tools 病在本道轻微。** v4.1 家族的「无工具时往文本流吐原始工具调用标记」病,在本道仅视觉案发作;OpenCode Go 道同病发作更重(详 [amber-opencode W37](https://github.com/getaskclaw/amber-opencode/blob/main/results/2026-W37.md))——同一模型名,转发层实现差异会改变行为面。
7. **全员同坑不粉饰。** A-87c472cb 6/8(±8h 边界,全员同坑)、A-d511f9e8 4/12(「正向清单病」照妖镜卷,全员同分同病)。
