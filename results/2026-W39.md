## Findings

1. **grok-4.7 的「plan-and-stop」交付病跨 provider 互证。** np-g47 有 7 案 transcript 同一形态：考生卷 + 一句「我先看…」计划 + **0 次工具调用** + 干净 cli_close——模型说完计划就交卷（A-791e90ac/A-1fd3683a/A-13854d9d/A-cdc3d11a/A-47eea242/A-ea80d793/A-d9b79b46）。cc 道同案废卷早前以「疑似配额墙」挂 contested；nous 道全程零 4xx、余额平滑、哨兵静默的无墙环境复现同形态 → 这 7 案的死法大概率是模型行为而非配额墙。**cc 道 7 案维持 contested 不抢先翻案**，待 09-29 周窗重置原道重考定音；nous 道因无墙证据确凿，7 案判模型负。
2. **A-87c472cb 四道同分 6/8**——全员同坑不粉饰（±8h 边界同族老坑），案级问题嫌疑置顶。
3. **A-d511f9e8 在 cc 双道 invalid_infrastructure**（1800s cap 撞顶），nous 道真跑 4/12——案可考，cc 道需排查这案为何两道连死基建。
4. **归因钉 A-a317e74b grok 进第一档**：cc 道 14/15、nous 道 13/15（历史最佳带 14/15）——高推理面确有料；过线要全钉，仍计挂。m26p 同案 10/15。
5. **text 面 FTM 三案三种死法**：m26p 全过（6/6、2/2、5/5）证题可过；grok 双道 plan-and-stop；m26f 也 no code block——交付可靠性成为本周三连考的最大区分面。
6. **m26p 亮点**：A-47eea242 拿 4（并列史上最佳，W37 纪录）；OPS 面 6/6 全过；唯一 invalid 即 Finding 3 的 A-d511f9e8。
